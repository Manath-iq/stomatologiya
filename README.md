# DENTIS — демо-лендинг стоматологической клиники

Демонстрационный сайт для портфолио: одностраничник клиники имплантации
и эстетической стоматологии. Клиника, врачи, отзывы, кейсы и реквизиты вымышлены,
изображения сгенерированы.

**Живая версия:** https://manath-iq.github.io/stomatologiya/

## Что внутри

Статика без сборки — открывается двойным кликом по `index.html`, деплоится
на GitHub Pages простым push в `main`.

```
index.html      главная, все тексты прямо в разметке
privacy.html    политика конфиденциальности и условия
404.html        страница ошибки
css/tokens.css  палитра, шкалы, радиусы, кривые движения
css/base.css    типографика, кнопки, состояния, ревилы
css/sections.css секции
js/             модули: навигация, веер, drag-ленты, компаратор, форма, скролл
img/gen/        изображения (webp)
```

Внешние зависимости — только шрифт Manrope с Google Fonts и GSAP + Lenis с CDN.

## Механики

| Что | Где | Как работает |
|---|---|---|
| Веерная карусель | `js/fan-carousel.js` | Карточки раскладываются по дуге; поворот, подъём и масштаб считаются от расстояния до центра. Мышь, стрелки, клавиатура |
| Drag-лента услуг | `js/drag-slider.js` | Инерционное перетаскивание с затуханием |
| До и после | `js/before-after.js` | Прозрачный `input[type=range]` поверх картинки двигает шторку |
| Пословное проявление | `js/reveal.js` | Слова оборачиваются в спаны и загораются по очереди при входе в кадр |
| Скролл-хореография | `js/main.js` | Lenis для плавности, ScrollTrigger для параллакса, орбит и прогресса |

Всё уважает `prefers-reduced-motion`: анимации отключаются, контент остаётся.

## Как переклеить под клиента

1. **Тексты, цены, врачи, контакты** — в `index.html`, никаких шаблонизаторов.
   Прайс лежит в секции `<!-- УСЛУГИ И ЦЕНЫ -->`, врачи в `<!-- ВРАЧИ -->`.
2. **Цвет акцента** — одна переменная `--lime` в `css/tokens.css`
   (и `--lime-deep` для наведения).
3. **Изображения** — заменить файлы в `img/gen/`, сохранив имена и пропорции.
4. **Реквизиты и юридика** — футер `index.html` и `privacy.html`:
   ИНН, ОГРН, лицензия, адрес, телефон.
5. **Метатеги и адрес сайта** — блок `<head>`: `title`, `description`,
   `canonical`, `og:*`, плюс JSON-LD `Dentist` в конце `index.html`.
6. Убрать из футера и `privacy.html` абзац о демонстрационном характере макета.

## Форма записи

Заявка никуда не отправляется — это макет. Чтобы включить приём заявок,
замените блок `setTimeout` в `js/form.js` на запрос к своему обработчику
(Formspree, Telegram-бот, CRM). Валидация, маска телефона и чекбокс согласия
на обработку персональных данных уже на месте.

## Локальный запуск

```bash
python3 -m http.server 4173
```

Затем откройте http://localhost:4173

## Деплой

Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
Все пути относительные, поэтому сайт работает и в подкаталоге.
